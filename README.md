# DustinYTDownloader Releases

`DustinYTDownloader`의 Windows 배포 파일과 자동 업데이트 정보만 제공하는 공개 저장소입니다.

- `DustinYTDownloader-Setup.exe`: Windows 설치 및 기존 버전 업데이트
- `DustinYTDownloader-Portable.exe`: 설치 없이 실행하는 포터블 앱
- `DustinYTDownloader-v1.6-Windows.zip`: 설치형·포터블형·안내문 통합 압축 파일
- `latest.json`: 앱이 시작할 때 확인하는 최신 버전 및 SHA-256 정보

현재 버전은 **1.6**입니다. Python을 별도로 설치할 필요가 없습니다. 앱은 첫 미디어 다운로드 때 공개 프로젝트인 yt-dlp와 FFmpeg를 사용자 로컬 데이터 폴더에 준비합니다.

본인이 소유했거나 다운로드 허가를 받은 콘텐츠에만 사용하고 YouTube 및 콘텐츠 제공자의 이용약관과 저작권을 준수하세요. 로그인, DRM, 유료 콘텐츠, 연령 또는 지역 제한 우회 기능은 제공하지 않습니다.

소스와 개발 문서는 비공개 저장소에서 관리합니다. 이 공개 저장소에는 인증 토큰이나 개인 정보가 포함되지 않습니다.
